# Domain Documentation

This project follows a **single-context** layout for domain knowledge.

## Locations

- **Context**: `CONTEXT.md` at the repository root contains the core domain language and system overview.
- **Architectural Decisions**: `docs/adr/` contains Architectural Decision Records (ADRs) following the standard format.

## Rules

- Always consult `CONTEXT.md` before proposing architectural changes.
- Record significant architectural choices as ADRs.
